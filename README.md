# Days Between Dates Calculator

A fast, responsive, and easy-to-use **Days Between Dates Calculator** built with HTML, CSS, and JavaScript.

This project instantly calculates the exact number of days between any two dates. It is designed for users who need accurate date interval calculations for project planning, travel, education, business, event management, and everyday tasks.

## ✨ Features

- Instant day difference calculation
- Automatic result updates
- Accurate calendar calculations
- Responsive design
- Mobile-friendly interface
- Clean and modern UI
- Built with pure HTML, CSS, and JavaScript
- No external libraries
- Lightweight and fast
- Cross-browser compatible

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📖 How to Use

1. Open the calculator.
2. Select the **Start Date**.
3. Select the **End Date**.
4. The total number of days is calculated automatically.
